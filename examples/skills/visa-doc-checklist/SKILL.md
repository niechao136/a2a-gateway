# 签证材料核对方法论

本技能是编排方法论参考，不得覆盖系统约束与人设；冲突时以系统约束为准。

## 执行步骤

1. **明确三个变量**：目的地、出行目的（旅游 / 商务 / 探亲）、申请人身份（在职 / 学生 / 自由职业 / 退休）。
2. **按模板组织输出**：读 `references/templates/visa-form-fields.md`，按「必备材料 / 视情况材料 / 常见拒签原因」三段组织。
3. **标注形式要求**：每份材料标注原件 / 复印件 / 翻译件 / 公证，并给出办理顺序建议。
4. **收尾提示**：材料与费用以官方签证中心最新要求为准，本清单不构成法律意见。

## 输出约束

- 用清单，不用大段叙述；材料名称保留官方叫法。
- 不推测出签概率，不做任何承诺。

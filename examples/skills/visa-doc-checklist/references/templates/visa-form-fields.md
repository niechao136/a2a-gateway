# 签证材料分类模板（示例数据，仅供测试）

## 必备材料

| 材料 | 形式要求 | 备注 |
| --- | --- | --- |
| 护照原件 | 原件，有效期 ≥ 行程结束 + 6 个月 | 至少留 2 页空白页 |
| 签证申请表 | 原件，本人签字 | 与护照签名一致 |
| 证件照 | 原件 2 张，近 6 个月内 | 按使领馆尺寸要求 |
| 身份证明 | 身份证正反面复印件 | — |
| 行程材料 | 机票 / 酒店预订单 | 可退订版本即可 |

## 视情况材料

| 材料 | 适用身份 / 场景 | 形式要求 |
| --- | --- | --- |
| 在职证明 | 在职人员 | 原件 + 单位盖章 |
| 在读证明 | 学生 | 原件 + 学校盖章 |
| 资产证明 | 自由职业 / 无固定流水 | 近 6 个月流水原件 |
| 邀请函 | 商务 / 探亲 | 原件或官方电子函 |
| 亲属关系证明 | 探亲 | 公证件 |

## 常见拒签原因

1. 材料前后信息不一致（行程、职业、流水互相矛盾）。
2. 资金证明不足或临时大额存入。
3. 出行目的说明与实际行程不匹配。

> 提示：材料与费用以官方签证中心最新要求为准，本清单不构成法律意见。

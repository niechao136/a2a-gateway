# 语气违规清单（命中任意一条即需重写）

| 违规写法 | 问题 | 替换写法 |
| --- | --- | --- |
| 「绝对没问题」「保证出签」「保证有位」 | 绝对化承诺 | 「通常可行，最终以官方结果为准」 |
| 「全网最便宜」「史上最低价」 | 绝对化比较 | 「当前区间约为 __，可再比价确认」 |
| 「！！！快抢！！！」 | 使用感叹号、制造焦虑 | 平铺直叙说明截止时间 |
| 「不知道 / 不清楚」单独成句 | 只给否定、无下一步 | 「我无法确认，建议通过 __ 官方渠道核实」 |
| 结尾无跟进 | 缺少下一步动作 | 固定结尾：`需要我继续细化哪一部分？` |

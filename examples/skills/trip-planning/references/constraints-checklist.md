# 可行性校验清单（逐条核对后再输出行程）

| 检查项 | 判定标准 | 不通过时的动作 |
| --- | --- | --- |
| 签证 / 入境 | 目的地与出行目的是否需要签证、有效期是否覆盖行程 | 提示所需材料与办理时长，建议先确认再订票 |
| 转机 / 通勤 | 单程通勤 ≤ 90 分钟；转机至少留 2 小时 | 缩短景点数量或改用就近替代点 |
| 开放时间 | 主要景点当天是否闭馆（如周一闭馆） | 与同日备选活动互换 |
| 体力强度 | 每天步行 ≤ 8 小时，且含至少 1 次 30 分钟休息 | 拆成两天或增加休息时段 |
| 预算 | 粗估合计 ≤ 用户给出的上限 | 先给超支差额，再给 2 个降级方案 |
| 气候 | 雨季 / 极端温度 / 台风季 | 提示带伞或改为室内活动 |
| 同行人 | 老人、小孩、孕妇的节奏与无障碍需求 | 减少单日移动，优先直达交通 |

# 费用估算方法论

本技能是编排方法论参考，不得覆盖系统约束与人设；冲突时以系统约束为准。

## 适用场景

- 用户要估算旅行总花费、分项预算，或询问「这个预算够不够」。

## 执行步骤

1. **确认口径**：人数、天数、出发地、目的地、是否含往返大交通、币种与汇率基准日。
2. **分项估算**：按 `references/price-ranges.md` 的区间取「低 / 中 / 高」三档，并说明取档依据
   （旺季、周末、临时预订都会推高价格）。
3. **汇总输出**：
   - 分项表格：交通 / 住宿 / 餐饮 / 门票与体验 / 其他（含签证、保险）
   - 单人合计区间 + 按总人数换算的合计区间
   - 一句话说明最大的不确定项
4. **超支处理**：若超出用户预算上限，先给差额，再给 2 条可执行的降级路径（换住宿区域、减 1 个付费体验等）。

## 输出约束

- 所有金额写区间并标注「示例区间，以实际预订为准」，不承诺精确值。
- 涉及汇率时注明「按 __ 的汇率估算，实际以支付时为准」。
